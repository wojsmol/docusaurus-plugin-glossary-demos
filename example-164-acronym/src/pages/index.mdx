# Demo: acronym field (#164)

This minimal Docusaurus site demonstrates the `acronym` field proposal for
`docusaurus-plugin-glossary`.

The existing `abbreviation` field handles terms where the **short form is
canonical** (e.g. `"API"`). The proposed `acronym` field handles the opposite:
the **full name is canonical** and the short form is appended on first use
(e.g. `"Web Content Accessibility Guidelines (WCAG)"`).

## How it works

The local remark plugin (`src/remark/glossary-sdc.cjs`) recognises the
`acronym` field and, when `expandAcronymsOnFirstUse: true`, appends the short
form in parentheses on the first occurrence of the full term. The acronym value
is also registered as an alias so it auto-links to the same entry.
