# shortDefinition demo

The `shortDefinition` field provides a **concise tooltip text** separate from
the full definition displayed on the glossary page.

When a term has `shortDefinition`, it is shown in the hover tooltip (or
popover) instead of the full `definition`. When `shortDefinition` is absent,
the full definition is used as a fallback.

---

## Terms with shortDefinition

Hover over the linked terms below to see the short definition in the tooltip.

Digital accessibility is the foundation of inclusive design. The practice
covers a broad range of disabilities: visual, auditory, motor, and cognitive.

Screen reader users navigate content using keyboard shortcuts and headings.
Many screen reader users never use a mouse at all.

Keyboard navigation is essential for users with motor impairments who cannot
use a mouse. It is also required by WCAG success criteria.

appears in the tooltip instead.
